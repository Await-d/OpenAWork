# Team 页面布局设计（合并版）

> ⚠️ **v3.12 修订提示（2026-05-16）**：本布局基于 v3.11 设计绘制。v3.12 已剥离 Phase A 的 SOUL/五层架构相关 UI，**Phase A 只需新增"团队宪法"侧边 tab**（详见 `team-architecture-phase-a-decisions.md`）。本布局中的 TeamStatusBar / OfficeThreeCanvas / 任务面板等元素属于 Phase B 及之后的设计。
>
> ---
>
> 用途：基于现有 team 页面代码 + v3.11 决策的合并布局方案
> 关联决策：D42/D44/D49/D53 + 现有组件复用
> 布局方案：C/A/D/A（对话为主 + 顶部固定栏 + 自适应抽屉 + 建议栏对话流末尾）
>
> 保留组件：OfficeThreeCanvas（3D AI 团队动画）
> 复用组件：ConversationTab / TasksTab / TopTeamHeader / TeamSessionSidebar / 各 use-team-\* hooks

## 2. 3D AI 团队动画（OfficeThreeCanvas 保留）

### 2.1 在新布局中的位置

```
┌─────────────────────────────────────┐
│  OfficeThreeCanvas（紧凑模式）       │
│  高度: 180px（可折叠为 0）           │
│                                     │
│  ┌───┐  ┌───┐  ┌───┐  ┌───┐       │
│  │ b │→ │ c │→ │ d │→ │e/f│       │
│  │ 💬│  │ 📋│  │ 🎯│  │ ⚡│       │
│  └───┘  └───┘  └───┘  └───┘       │
│                                     │
│  [▼ 折叠动画] [⛶ 全屏]             │
└─────────────────────────────────────┘
```

### 2.2 动画与运行状态联动

| 状态         | 动画表现                                       |
| ------------ | ---------------------------------------------- |
| 无任务       | agent 节点静止/待机动画                        |
| 💬助手接待中 | 助手节点高亮 + 对话气泡动画                    |
| 📋规划中     | 规划师节点高亮 + 文档编写动画                  |
| 🎯派发中     | 主管节点高亮 + 连线动画（主管→开发/测试/审查） |
| e/f/g 执行中 | 对应节点高亮 + 工作动画                        |
| 暂停         | 所有节点灰色 + 暂停图标                        |
| 失败         | 失败节点红色闪烁                               |

### 2.3 交互

| 操作            | 行为                                           |
| --------------- | ---------------------------------------------- |
| 点击 agent 节点 | 右侧面板跳转到该层的 session 详情              |
| 折叠按钮        | 动画区域收起为 0 高度，对话区获得更多空间      |
| 全屏按钮        | 动画区域扩展为全屏（类似现有 Office Tab 体验） |
| 悬停节点        | 显示该层当前状态 tooltip                       |

### 2.4 复用现有组件

```
现有：OfficeThreeCanvas.tsx + OfficeScene.tsx
改造：
  · 从独立 Tab → 嵌入对话区上方（紧凑模式）
  · 添加折叠/全屏切换
  · 添加与 handoff_records 状态的实时联动
  · 节点数量从固定 → 动态（D46 动态编制，e 可能有 2-5 个）
```

## 13. 层级对话查看器（底部抽屉 + Tab 切换）

### 13.1 触发方式

```
用户点击 Session 树中的任意层节点（如 c / d / e1）
    或
用户点击顶部状态栏的 LayerStatusIndicator 中某一层
    或

### 13.6 与主对话区的关系

```
底部抽屉展开时：
  · 主对话区被压缩（高度减少）
  · 用户仍可在主对话区输入消息（a-b 同步对话不中断）
  · 3D 动画区域自动折叠（让出空间）
  · 右侧面板不受影响

底部抽屉关闭时：
  · 主对话区恢复全高
  · 3D 动画区域恢复（如果之前未手动折叠）
```

```
移动端（< 768px）：
  · 底部抽屉上滑为全屏覆盖（不是半屏）

  · 无拖拽调整高度（固定全屏）
