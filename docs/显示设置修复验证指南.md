# 显示设置修复验证指南

## 修复内容

修复了推理块折叠设置不生效的问题。

### 问题描述

之前当你在"显示设置"中切换"推理过程默认展开"开关时，聊天界面中已经存在的推理块不会响应设置变化。

### 修复方案

- 推理块组件现在直接从 store 读取设置
- 设置变化时自动更新所有推理块的展开状态
- 用户手动操作的推理块会保持用户选择的状态

## 技术细节

### 修改的文件

- `apps/web/src/components/chat/assistant/assistant-reasoning-block.tsx`

### 关键修改点

1. **导入 store**：

   ```typescript
   import { useDisplayPreferencesStore } from '../../../stores/settings/display-preferences.js';
   ```

2. **直接读取设置**：

   ```typescript
   const reasoningExpandedByDefaultPref = useDisplayPreferencesStore(
     (s) => s.reasoningExpandedByDefault,
   );
   ```

3. **响应设置变化**：

   ```typescript
   const [userInteracted, setUserInteracted] = useState(false);

   useEffect(() => {
     if (!userInteracted) {
       setExpanded(reasoningExpandedByDefaultPref);
     }
   }, [reasoningExpandedByDefaultPref, userInteracted]);
   ```

4. **标记用户操作**：
   ```typescript
   onClick={() => {
     setExpanded(true);
     setUserInteracted(true); // 标记用户已手动操作
   }}
   ```

### 为什么之前不工作

```typescript
// ❌ 问题代码（修复前）
const [expanded, setExpanded] = useState(defaultExpanded);
// defaultExpanded 只在组件挂载时读取一次，后续 prop 变化不会触发更新
```

### 为什么现在工作

```typescript
// ✅ 修复后
const setting = useDisplayPreferencesStore((s) => s.reasoningExpandedByDefault);
useEffect(() => {
  if (!userInteracted) {
    setExpanded(setting); // 设置变化时自动更新
  }
}, [setting, userInteracted]);
```

## 常见问题

### Q: 修改设置后需要刷新页面吗？

**A**: 不需要。修复后设置变化会实时生效。

### Q: 历史消息会自动更新吗？

**A**: 会。修复后历史消息的推理块会响应设置变化，但用户手动操作过的推理块除外。

### Q: 如果我手动展开了一个推理块，后续修改设置会影响它吗？

**A**: 不会。用户手动操作的优先级最高，设置不会覆盖用户的选择。

### Q: 工具调用的折叠设置为什么之前就是正常的？

**A**: 工具调用组件使用了不同的实现方式：

- 通过 `useToolExpandDefault()` hook 每次渲染时都读取最新设置
- 没有使用 `useState(prop)` 的模式，所以不受此问题影响
