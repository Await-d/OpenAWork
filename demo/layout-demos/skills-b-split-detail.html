web-search-plus

多引擎检索与结果去重，附带引用整理与可信度排序；适用于需要外部事实支撑的任务。

v1.3.0 ✓ 已验证 检索 网络 已装 v1.2.0 · 可更新

这个技能做什么

把「先查外部资料再给结论」这件事固化成流程：并发查询多个引擎、按域名与时间加权去重， 最后把引用整理成可回溯的脚注列表。

什么时候会用到

  • 任务需要外部事实、版本号、库的最新用法
  • 需要给结论附上可点击的来源
  • 需要排除内容农场与过期文档

安装后如何触发

用户：帮我确认 zod 4 的 object().strict() 是否已废弃
Agent → 调用 skill: web-search-plus
       → 并发检索 4 个引擎 → 去重 → 引用排序 → 结论 + 来源

示例输出

结论：zod 4 保留了 .strict()，但官方推荐 .object().strict() 的等价写法 .strictObject()。
来源：
  1. zod 官方迁移指南（zod.dev/v4/changelog） · 2026-08-14

与内置能力的差异

  • 内建 web_search 只返回原始结果；本技能额外做去重与可信度排序
  • 输出带引用编号，可直接被文档与报告复用

web-search-plus

多引擎并发检索（Brave / Tavily / SerpAPI / DuckDuckGo），支持时间窗过滤、域名白名单与黑名单。 

# 安装
openawork skill install web-search-plus

# 环境变量
SEARCH_BRAVE_KEY=...
SEARCH_TAVILY_KEY=...

配置项

  • engines：参与并发检索的引擎列表
  • maxResults：合并后保留的结果数（默认 12）
  • blocklist：需要排除的域名

该技能会请求的权限

  • 读取环境变量 SEARCH_*_KEY（网络凭据）
  • 发起出站 HTTPS 请求（仅限已声明的引擎域名）
  • 写入会话级缓存目录

安装即表示授予上述权限；可在「设置 → 插件 → 技能」中随时撤销。
