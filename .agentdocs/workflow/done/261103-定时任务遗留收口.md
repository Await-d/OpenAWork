## 关键决策

1. **选择只读不写**：切到 `session` 只是「挂起」，`delivery_target` 必须由用户显式选中后才写 —— 旧实现 `prompt` 取消/留空是静默放弃，用户无从得知本次没生效。
2. **会话列表懒加载**：`enabled` 门控在弹层打开时才请求，避免每次进页面多拉 100 条会话（`GET /sessions` 无 offset 分页，固定上限 100）。
3. **表单仍显示会话 id**：执行器按 id 查会话（网关 `assertOwnedSession`），显示 id 便于用户核对；不额外查标题是为了少一次请求。
4. **`CronManager` 直接删除而非标记废弃**：全仓（含 mobile/desktop）零消费方，保留只会诱导后续误用；`shared-ui` 的其它导出与 `tokens` 色值不受影响（已核实多处仍在用）。

## 踩坑记录

1. **同一文件并行两次 `replace` 会丢一次写入**：给 mock 网关同时插「常量」与「路由分支」时，后一次覆盖前一次，导致运行期 `sessions is not defined`。**规则：同一文件的多次编辑必须串行**。
2. **不要用 `eval` 移除 React 管理的 DOM**：走查中把遥测弹窗 `remove()` 掉后，React 后续操作该节点抛错并整页落进错误边界（页面显示「界面渲染出错」）。关弹窗必须点它自己的按钮；已持久化的首次引导（「跳过引导，直接登录」/「不了，谢谢」）之后不会再出现。
3. **agent-browser 的 `select` 命令匹配不到中文 `aria-label` 选择器**：改为在 `eval` 里用原生 value setter + `dispatchEvent(new Event('change', { bubbles: true }))`，React 受控组件才会响应。
4. **`DialogError` 自带「操作失败：」前缀**：断言要按子串/`role="alert"` 匹配，不能精确匹配整段文案。
