# 260924-自定义 Agent 管理工具（agent_manage）

## Task Overview

按「AI 自助管理」范式（域四之一），新增模型可见工具 `agent_manage`
（list / create / update / delete / reset），复用 `/agents` 路由的校验与 catalog 服务。
**团队工作区工具（`team_workspace_manage`）本域暂缓**，理由与后续计划见文末。

## Current Analysis

- 现状入口：`routes/agents.ts`（GET/POST/PUT/DELETE + reset / reset-all），
  服务层 `agent/agent-catalog.ts`（`listManagedAgentsForUser` / `createManagedAgentForUser` /
  `updateManagedAgentForUser` / `removeManagedAgentForUser` / `resetManagedAgentForUser`）。
- 存储：`user_settings.agent_catalog`（内置覆盖 + 自定义 Agent），读取按请求 ⇒ 变更即时生效。
- 约束：`systemPrompt` 有长度上限（`MODEL_REQUEST_SYSTEM_PROMPT_MAX_CHARS`）；
  内置 Agent 只允许改模型配置（`builtinUpdateRestricted`）；内置不可删除。
- 模型侧原本无任何 Agent 管理工具（只有 `Agent` / `call_omo_agent` 调用）。

## Solution Design

- **同源复用**：`routes/agents.ts` 导出 `createManagedAgentSchema` /
  `updateManagedAgentSchema` / `mapAgentCatalogError`（纯改名导出，无逻辑改动），
  工具直接引用——校验与中文错误文案不复制。
- 工具 schema：`{ action, agentId?, agent? }`；create 用 create schema，update 用 update schema；
  delete/reset 需 agentId；list 免参。
- 权限：新类别 `agent_manage`（ask）；`list` 免审批；变更动作 `scope=action:agentId|new`，
  `always=[action:*]`；预览展示 Agent 标识。
- 会话守卫：team / cron / channel 拒绝；可见性同源隐藏；能力目录第五条提示。
- 输出：`{ id, label, description, source, enabled, model, variant, systemPromptPreview }`
  （systemPrompt 截断 200 字）。
