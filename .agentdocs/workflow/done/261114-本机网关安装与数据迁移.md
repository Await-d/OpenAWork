# 本机网关安装与 Docker 数据迁移

## 任务概述

交付可重复使用的 Linux 本机安装和更新脚本，在当前主机安装运行网关，保留 Docker 对话数据并启用浏览器实时预览。

## 当前分析

- 现有网关使用 Docker，端口 8000，SQLite 与附件在 deploy/data（约 1.8 GiB）。
- 宿主用户 await 无免密 sudo，支持 systemd 用户服务；当前未启用 linger。
- 数据包含容器绝对路径，需要按实际挂载映射迁移；JWT 密钥保持一致。
- Docker 数据独立保留；迁移时停止源实例并关闭自动重启，避免多实例和定时任务并发。

## 方案设计

1. 安装与更新脚本使用用户级 systemd，环境文件权限 0600，显式 Node/Bun 路径。
2. 浏览器先安装 Playwright Chromium 并真实启动验证，再启用 OPENAWORK_BROWSER_LIVE=1。
3. 冷备份后复制数据库、附件与文档，迁移副本中的结构化路径，保留原始记录正文。
4. 保持访问端口 8000；验证完整性、记录数、Web 页面和浏览器实时预览。
