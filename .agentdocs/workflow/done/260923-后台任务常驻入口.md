# 260923-后台任务常驻入口（胶囊 + 浮动栏）

## 任务概览

「后台任务面板」（已交付：classic `ChatRightPanel` tab / Fusion `FusionSessionSidePanel` tab）解决了「统一查看」，但仍需要用户主动切 tab。本方案补**常驻入口**，让用户在对话页随时**知道**有后台任务在跑并**就地处理**：

- **Phase 1（先行）**：输入框上方左侧（`composerFooterSlot`）的**常驻胶囊 + 展开列表**；
- **Phase 2**：把左侧浮动栏（`SubAgentRunList`）升级为**统一「后台任务」浮动栏**（子代理 + 后台命令两组）。

## 方案设计

### Phase 1：常驻胶囊 + 展开列表（先行）

- **落点**：`composerFooterSlot` 内、「选择工作空间」右侧（左对齐一行）。
- **胶囊**：`⚙ 后台 N`（N = `runningSubagents + runningShells`），有运行中时带脉冲点；`title` 给出细目（`N 个子代理运行中 · M 个后台命令`）；仅当 `activeTotal > 0` 渲染（全部完成后自动消失，避免常驻噪音）。
- **展开列表**：点击向上弹出面板（宽 320px，最多 6 行 + 「查看全部（N）」）：
  - 子代理行：状态点 + 标题 + `@agent` + `[打开子会话]` `[停止]`
  - 命令行：状态点 + command 单行省略 + `[查看]` `[终止]`
  - 底部固定入口：`打开后台面板`（classic → 切 `terminals`? 不——切「后台任务」tab；fusion → `sidePanelActiveTab='background'`）。
- **破坏性操作**：复用 `BackgroundTaskPanel` 的确认弹窗语义（`AppDialog` + 同一套提示文案），逐行确认后调回调。
- **数据与回调**：全部复用 `useBackgroundTaskPanel` 输出与既有回调（`handleStopChildSession` / `handleStopAllChildSessions` / `terminal.killTerminal` / 预览终端 / `openChildSessionInspector`）；**组件内不发请求**。
- **可访问性**：胶囊为原生 `button`（`aria-haspopup="dialog"`、`aria-expanded`），弹出层 `role="dialog"` + Esc 关闭 + 焦点回胶囊；focus ring 走 token。

### Phase 2：左侧浮动栏升级为「后台任务」浮动栏

- `SubAgentRunList` 扩展为可接收 **`shellItems`**（后台命令）并渲染第二个分组「后台命令」；分组标题带计数；命令行复用 `ShellTaskRow` 的展示与操作语义（查看/终止）。
- 折叠态迷你胶囊：`后台 N 运行中`（原为子代理计数）；折叠偏好键保持兼容（`chat.subagentRunList.collapsed`）。
- **向后兼容**：`shellItems` 可选；不传时行为与现状逐字节一致（team 端也复用该组件，必须零回归）。
- 入口切换一致性：浮动栏展开时点击条目行为与「打开后台面板」的分工保持单一来源（浮动栏＝就地处理，面板＝全量视图）。

### 非目标

- 跨会话后台管理；后台任务持久历史；移动端（`apps/mobile` 不复用 web 组件）；修改模型侧工具契约。

1. **单测**：胶囊显隐/展开/操作/键盘；rail 扩展的向后兼容（不传 `shellItems` 与现状一致）。
2. **真实浏览器 harness**：复用 `apps/web/harness/background-task-panel-*` 基建，追加 chip 用例（3 视口坐标 + 操作链路）。
3. **实机只读冒烟**（dev server + 真实会话）：Fusion 与 classic 各一次 —— 只读断言「0 活跃 → 胶囊不出现」；活跃态由 harness 覆盖（不在用户会话里制造后台任务）。

## 风险与缓解

- **R-01 常驻噪音**：只在有运行中任务时渲染；不显示历史（历史在面板里）。
- **R-02 弹出层遮挡输入**：向上弹出、最大高度受限、Esc/点击外部关闭；定位参考同 slot 的 `ComposerWorkspaceMenu` 先例。
- **R-03 Phase 2 回归面**：`SubAgentRunList` 有 team 端消费 → `shellItems` 必须可选且缺省零变化；改动文件为单写者（协调者/单一 agent）。
- **R-04 双入口分歧**：胶囊/浮动栏/面板三处动作都走同一批回调与同一确认弹窗，禁止各自实现"停止"逻辑。
