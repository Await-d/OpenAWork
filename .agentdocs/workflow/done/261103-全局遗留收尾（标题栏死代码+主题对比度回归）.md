## ② 主题对比度回归

**主题清单**（`index.css` 的 `data-theme`）：aurora / carbon / forest / linear / nebula / ocean / sakura / sunset，各带 `data-mode='light' | 'dark'` → **16 档**。

**方法**：agent-browser 逐档设置 `documentElement.dataset.theme/mode` 后逐档跑 axe；**每档先校验「健康度 + 主题身份」**（`cards=6`、`main=1`、`--fg-muted` 计算值与该主题新值一致），不合格自动重试（≤3 次）。

**修复前：26 个对比度节点**（本页 8 个），根因只有两个：

| 根因 | 证据 | 连带面 |
| --- | --- | --- |
| **6 套主题的 `--fg-muted` 略低于 4.5:1** | carbon-dark 3.84/4.01/4.13/4.23、sunset-dark 4.04/4.24/4.4/4.49、linear-light 4.47、linear-dark 4.43、ocean-dark 4.39、sakura-dark 4.44 | `.page-subtitle`、`.sidebar-list-state-hint`、版本角标 `footer > span`、视图切换按钮，以及本页的 `.sch-track-hours > span` 与 `.sch-chip` |
| **`.sidebar-primary-action` 彩字压在 accent 淡底上** | forest-light `#128a40` on `#f3faf6` = **4.18**、nebula-light `#515fe8` on `#d9ddf5` = **3.75** | 侧栏「新建会话 / 新建任务」主操作按钮 |

**修复**：

1. 按每个主题**实测最差底色反推**新色值（目标 ≥4.7:1，只挪 HSL 亮度、保持色相与饱和度）：

   | 主题块 | `--fg-muted` | 最差底色 | 对比度 |
   | --- | --- | --- | --- |
   | carbon-dark | `#6e747e` → `#7c828d` | `#151618` | 3.85 → 4.71 |
   | sunset-dark | `#8a7568` → `#958073` | `#221613` | 4.05 → 4.71 |
   | linear-light | `#6a7184` → `#676e80` | `#f4f5f9` | 4.47 → 4.70 |
   | linear-dark | `#7a8194` → `#7f8698` | `#161b25` | 4.43 → 4.71 |
   | ocean-dark | `#6a8898` → `#708d9c` | `#102128` | 4.40 → 4.72 |
   | sakura-dark | `#8e7a88` → `#927e8c` | `#201520` | 4.45 → 4.71 |

2. 侧栏主操作按钮：强调改由**底色 + 内描边**承担（`background: var(--accent-subtle)` 保留 + 新增 `box-shadow: inset 0 0 0 1px var(--accent-border)`），文字改 `--fg-strong`。理由：彩字方案跨主题不可控 —— `--accent` 4.2~4.3、`--accent-hover` 3.75~4.18，再深一档（`--accent-active`）在**暗色主题会反向变差**（深字压深底）。这与页面内 `.sch-chip[aria-pressed]` 的既定约定一致：「状态靠背景与描边表达，文字用高对比 token」。

## 踩坑记录

1. **主题回归必须做「健康度 + 身份」双重校验**：中途有 3 档（linear-dark / nebula-light / nebula-dark）页面落进**错误边界**（`cards=0`、`main=0`），此时 axe 几乎必然全 0 —— 不做校验就会把「页面崩了」误读成「对比度达标」。终版脚本改为**每档重载页面 → 校验（cards=6 / main=1 / `--fg-muted` 身份）→ 合格才计入，不合格重试**。（这也是本轮发现 `/workflows` 崩溃同源问题的同一类陷阱。）
2. **别用 `getComputedStyle(body).backgroundColor` 当主题身份**：时序噪声大（实测出现"亮档读到暗档底色"）。用**该主题独有的 token 值**（如 `--fg-muted`）判断可靠得多。
3. **同文件多处机械替换可以用一条 `sed` 命令**：本次 6 个 `--fg-muted` 值都在 `index.css` 且各自唯一，一条命令完成 —— 避免同文件 6 次串行编辑（工具层同文件并行/连续写入会丢改动，前几轮已踩）。改完立刻 `grep` 校验新值到位、旧值清零。
