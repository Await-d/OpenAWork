# 260924-团队工作区管理工具（team_workspace_manage）

## Task Overview

四域顺延项：按「AI 自助管理」范式新增 `team_workspace_manage`
（list / create / update / delete），复用 `/team/workspaces` 的持久化语义，并对
roster 的能力绑定（`skillIds` / `mcpServerIds`）做白名单校验。

## Current Analysis

- 现状入口：`routes/team.ts`（3673 行）内联实现 5 个 handler
  （list / get / create / update / delete），行映射 `mapWorkspaceRow` 为闭包内箭头函数。
- 存储：`team_workspaces`（`default_team_roster_json` 保存 roster 快照）；
  roster 归一在 `team/team-default-roster-store.ts`
  （`normalizeTeamWorkspaceDefaultRoster` / `parseTeamWorkspaceDefaultRosterJson` /
  `cloneDefaultTeamRoster`，`normalizeMemberSlot(entry: unknown)` 严格校验必填字段）。
- **已知静默行为**：`normalizeTeamWorkspaceDefaultRoster` 在归一化后为 0 条时会
  **回退默认 roster**——工具必须显式检测「输入了 roster 但被丢弃」并报错，
  不能让模型以为配置了成员却得到默认编制。
- 能力绑定：slot 的 `skillIds` / `mcpServerIds` 在路由层**无校验**；工具必须补。
- 回归网：`__tests__/team/team-workspace-roster-routes.test.ts`、
  `__tests__/routes/team-main-routes.test.ts`。

## Solution Design

**前置抽取**：新增 `team/team-workspace-store.ts`（`TeamWorkspaceRow` + `mapWorkspaceRow` +
list/get/create/update/delete），`routes/team.ts` 的 5 个 handler 改为调用
（与域二 `skill-installed-store` 同级的抽取边界，纯落库语义，不含网络/聚合）。

**工具** `team_workspace_manage`：
- `list`：本人工作区列表（含 roster 摘要）。
- `create` / `update`：`name / description / visibility / defaultWorkingRoot / defaultTeamRoster`；
  roster 以原始对象数组传入，归一化后**数量校验**（输入非空但被丢弃 → 报错并列出下标），
  再逐项校验绑定白名单：
  - `skillIds` ∈ 内置技能（`BUILTIN_SKILLS`）∪ 已安装技能（`listInstalledSkillsForUser`）；
  - `mcpServerIds` ∈ `loadConfiguredMcpServersForUser` 合并列表；
  - 违规 → 明确错误列出未知 id。
- `delete`：删除工作区（仅本人；语义与路由一致——只删工作区行，历史会话保留）。
- 权限：新类别 `team_manage`（ask）；`list` 免审批；变更 `scope=action:workspaceId|new`，
  `always=[action:*]`；预览展示名称 / 可见性 / roster 成员数 / defaultWorkingRoot。
- 守卫：team / cron / channel 拒绝（团队会话不得改团队配置）；可见性同源隐藏；
  能力目录第六条提示。
