## 踩坑记录

1. **JSX 注释不能放在 `return (` 之后、根元素之前**：那里不是 JSX 子元素位置，`{/* … */}` 会直接语法报错（本次在 `HomePage` / `ResourcesPage` 踩到，`tsc` 报 `TS1005`）。注释要放在 `return` 之前（`//`）或元素内部。
2. **改标签必须连带改 CSS 标签选择器**：本项目 CSS 主流是 class 选择器，但**自有组件里也有标签选择器**（`.sch-card-title h3`）—— 勘察时只审计了 `apps/web/src/**/*.css` 的既有文件，漏了自己新写的。改标签后必须 grep 该组件 CSS。
3. **`opacity` 降透明会一起压低文字对比度**：用 `opacity` 表达「已停用」在 axe 里等于把整卡文字对比度乘 0.72（实测 3.18）。用边框/背景表达状态更安全。
4. **`aria-expanded` 只能挂在支持它的角色上**：`input[type=search]` 不允许，必须补 `role="combobox"`。
