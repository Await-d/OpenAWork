## Solution Design

### 工具设计（`plugin_manage`）

| action | 语义 | 权限 |
|---|---|---|
| `list` | 已安装插件（状态/installId/guarded/来源） | 只读免审批（派生器返回 null） |
| `search` | 市场搜索（query？） | 只读免审批 |
| `source_list` | 市场源列表 | 只读免审批 |
| `install` | 安装：市场条目（sourceId+name）或 GitHub（repo/path/ref） | ask；预览含来源仓库/ref/路径 + **「无沙箱」信任提示** |
| `uninstall` | 卸载（installId） | ask；预览含插件 id 与目录 |
| `enable` / `disable` | 启停（pluginId） | ask；guarded 拒绝 |
| `reload` | 重载（installId） | ask |
| `source_add` / `source_remove` | 市场源增删（repo/ref，sourceId） | ask |

- 会话守卫（fail-closed）：team / cron / channel 会话拒绝（插件是网关全局代码执行面）
- 输出：人类可读字符串（对齐 mcp_manage_servers 的 `z.string()` 输出），安装结果含激活状态；失败返回明确错误文本（工具不抛业务异常，除守卫拒绝）
- 参数校验：market 安装必须给全 `sourceId+name`；GitHub 直装必须给 `repo`；`uninstall/reload` 必须给 installId；`enable/disable` 必须给 pluginId——`superRefine` fail-closed

### 权限派生器（预览要点）

- scope：`${action}:${target}`（target=installId/pluginId/sourceId/repo 或 `new`）
- `always: [action:*]`（一次永久允许只覆盖同一动作类型）
- `riskLevel: 'high'`（安装 = 持久化代码执行）
- 审批预览标题：
  - install：`安装插件 <name|repo>（<repo>@<ref> 路径 <path>）——插件将以网关权限执行任意代码`
  - uninstall：`卸载插件 <installId>（目录与存储数据将删除）`
  - enable/disable/reload/source_*：动作 + 目标

## Notes

- **安全不变式**：install 的下载/解压路径完全复用市场实现（bounded + zip 炸弹/zip-slip 防护）；guarded 插件拒绝卸载/停用；权限默认 ask 且不进免审批名单。
- **不做**：本地路径安装不进工具（模型不应直传服务器文件系统路径）——只支持市场条目与 GitHub 直装；`?plugin=` UI 交互仍由用户完成。
- **验收契约**：
  1. 普通会话 ask pending → 批准后安装成功并回传激活状态；拒绝则无副作用。
  2. team/cron/channel 会话工具不可见且执行被守卫拒绝（双保险）。
  3. `list/search/source_list` 不触发审批；变更动作的「永久允许」只覆盖同 action。
  4. 安装结果包含「插件将以网关权限执行」提示与来源信息，模型可据此向用户交代。
