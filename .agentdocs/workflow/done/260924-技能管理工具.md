# 260924-技能管理工具（skill_manage）

## Task Overview

按「AI 自助管理」范式（域二），新增模型可见工具 `skill_manage`
（list / install / uninstall / enable / disable），让会话内模型在用户审批下管理技能；
并先把 `routes/skills.ts` 的安装/卸载/启停落库逻辑抽成共享存储层，路由与工具同源。

## Current Analysis

- 现状入口：`routes/skills.ts`（2417 行）——`POST /skills/install`（三来源：注册源 /
  `github:` / `claude-marketplace:`，inline upsert）、`DELETE /skills/installed/:skillId`
  （事务级联清理）、`PATCH /skills/installed/:skillId[/enable]`（启停）；模型侧无工具。
- 存储：`installed_skills`（`(skill_id,user_id)` 冲突覆盖安装，`granted_permissions_json='[]'`）、
  `chat_workspace_skill_selections` / `chat_session_skill_overrides`（卸载时清理）。
- 生效性：`getEffectiveSkillsForSession` / `capabilities` 均按请求读库 ⇒ 变更即时生效。
- 回归网：`__tests__/routes/skills-routes.test.ts`（12 例，真实内存 SQLite + 真实路由）。

## Solution Design

**前置重构（已落地）**：新增 `skill/skill-installed-store.ts` 共享存储层——
`rowToInstalledSkill` / `tryRowToInstalledSkill` / `upsertInstalledSkill` /
`uninstallSkillForUser` / `setInstalledSkillEnabled` / `listInstalledSkillsForUser`；
`routes/skills.ts` 改为调用（安装 upsert、卸载事务、启停更新），并导出
`createRegistryClient` 供工具复用；`skill-installed-store` 不含注册源 / 网络依赖。

**工具**：`skill_manage`
- `list`：已安装技能摘要（skillId / sourceId / enabled / name / version /
  declaredPermissions / hasMcp），只读免审批；
- `install`：`{ skillId, sourceId? }` → `createRegistryClient(userId).install(...)` →
  `upsertInstalledSkill`；**v1 拒绝** `github:` / `claude-marketplace:` 前缀（引导设置页）；
- `uninstall` / `enable` / `disable`：共享存储层；未安装给可读错误。

**权限**：新类别 `skill_manage`（ask）；`list` 免审批；变更动作 `scope=action:skillId`，
`always=[action:*]`；预览展示 skillId + 来源。

**会话守卫**：team / cron / channel 拒绝（技能影响用户级 Agent 工具面）；
可见性同源隐藏（与 MCP / 记忆共用 helper）；clarify 自动排除。

**提示词**：能力目录第三条指引（仅对可见会话）。
