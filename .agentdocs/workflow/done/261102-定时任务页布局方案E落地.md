## Solution Design

1. **页面瘦身为装配层**：`SchedulesPage.tsx` 只保留 hook 调用 + 视图切换 + 区块拼装（目标 ≤250 行，符合 1500 行上限与「组装层例外登记」精神）。
2. **纯计算下沉 utils**：相对时间（几分钟/几小时/几天后）、本地日差分组、24h 轨道 mark 位置 —— 全部纯函数 + 单测，页面不写时间算术。
3. **两个视图消费同一份渲染数据**：卡片视图与时间轴视图都由 `jobs` 派生，展开历史共用 `historyView`（一次只展开一条，避免多份历史请求）。
4. **样式用页面级 CSS 文件**（对齐 `pages/home/home.css`、`pages/resources/resources-page.css` 既有约定），替代现在大量 inline style，便于窄屏断点与主题变量覆盖。
5. **概览卡数据全部本地派生**：KPI/轨道不改 hook、不新增请求；`今日还将执行` 依赖 `nextFireAt` 落在本地当天，用页面本地时区计算。

## Invariants（落地不得回归，均有既有测试或注释背书）

1. **渠道任务不得出现投递下拉**：`delivery_mode: 'channel'` 渲染纯文本「渠道回发」，`SchedulesPage.test.tsx:104-108` 断言 `queryByRole('combobox')` 为 `null`（该用例同时断言「禁用」只调 `setEnabled`、不回写 `update`）。
2. **历史入口的无障碍名**现有断言为 `名称 · 上次 xxx` / `名称 · 未执行`（`SchedulesPage.test.tsx:114`）→ 改成「执行历史」按钮必须**同步改测试**，并保证「上次执行时间」仍在卡片可见。
3. **`expired` 必须灰字「已过期」**，不得落到绿色或「运行中」（`SchedulesPage.test.tsx:111-118`）。
4. **`at` 类型时间一律走客户端本地时区**（`SchedulesPage.tsx:42-48` 既有注释：网关进程时区常为 UTC，直接用下发字符串会差 8 小时）→ 倒计时与时间轴刻度都走 `formatTimestamp`。
5. **失败必须主动推到顶部**（`FailedRunsPanel` 的既有意图：任务「显示成功、实际什么都没做」是历史缺陷，不能退回成只藏在抽屉里）。
6. **SSE / 轮询门控**：页面激活 **且** 文档可见才拉取（R-04 / R-05 结论），不得在非活动页建流或轮询。
7. **不改 `shared-ui` 导出契约**，`CronManager` 保留（见 D-04）。
